# HavenEstates — Find a Home You'll Love

An elegant real estate platform built with **React 18 + Vite + Tailwind CSS + Framer Motion**.

## Features

- **Home** — parallax hero with live search, featured residences, neighbourhood guides, testimonials
- **Listings** — search, property-type / bedroom / price filters, 4 sort orders, animated grid
- **Property pages** — photo gallery with lightbox, amenity lists, agent contact card with viewing-request form
- **Mortgage calculator** — interactive sliders with an animated donut chart (principal vs interest)
- **Saved homes** — shortlist persisted in localStorage
- **Contact page** — validated enquiry form
- Fully responsive, refined serif + forest-green design language

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

All property names, descriptions and photography are original content created for this concept project.
